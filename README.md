# AServices header

A responsive HTML, CSS and jQuery implementation of the AServices navigation header, minibus rental home hero, rental-benefits overview, and a minibus introduction section.

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server. jQuery is loaded from the official jQuery CDN.

## Layout

The centered `.container` uses a 1270px outer maximum width with 15px side padding, leaving 1240px of inner content at desktop sizes. The navigation collapses into an accessible mobile menu below 701px. The hero uses the supplied minibus photograph in `assets/minibus-hero.jpg`, with responsive text, availability CTA, and a tap-to-call contact link. The next section presents rental benefits alongside the day-rate summary, stacking into one column on smaller screens. The following introduction section pairs the supplied minibus photograph with responsive travel copy and a minibus examples link.
