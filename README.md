# AServices header

A responsive HTML, CSS and jQuery implementation of the complete AServices minibus-rental homepage.

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server. jQuery is loaded from the official jQuery CDN.

## Layout

All sections share the same centered `.container`: 1270px outer maximum width with 15px side padding, leaving 1240px of inner content at desktop sizes. The page includes the responsive header and hero, rental benefits and pricing, minibus introduction and options, travel inspiration cards, a three-step booking guide, expandable FAQs, a contact form, and footer. The contact form opens a pre-filled email draft; the page has no server-side form backend. jQuery powers the mobile navigation, form handling, and current footer year.
